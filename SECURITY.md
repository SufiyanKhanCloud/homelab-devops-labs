# Security Policy

## Scope

This repository contains documentation and sanitized examples from a
personal learning homelab.

## Reporting a Security Concern

If you discover a security issue in this repository, please report it
privately to the repository owner rather than publishing sensitive
details in a public issue.

## Sensitive Information

This repository must not contain:

- Passwords, API tokens, or authentication secrets
- SSH private keys or Tailscale authentication keys
- Database backups containing real data
- Environment files containing credentials
- Personal information or unnecessary infrastructure identifiers
- Raw logs or screenshots that expose sensitive information

## Lab Safety

Experiments are performed on infrastructure controlled by the author
or systems for which explicit authorization has been granted.

Commands and configurations are reviewed before being shared publicly.

## Limitations

This policy does not mean that the homelab is production infrastructure.
Experiments, limitations, and unverified assumptions are documented
honestly.
