# Diagrams

Architecture diagrams are maintained in Markdown using Mermaid wherever possible, allowing GitHub to render them directly.

Exported diagrams and screenshots must be reviewed before publication to ensure they do not expose:

- Credentials, tokens, or private keys.
- Private network identifiers or internal hostnames.
- Personal information or account identifiers.
- Other sensitive infrastructure details.

Diagrams should reflect the verified implementation and remain consistent with the repository documentation.
